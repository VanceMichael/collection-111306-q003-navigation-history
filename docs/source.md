# 本地资料源约定

按钮通过真实 history.pushState 改路由，同 URL 也可创建新历史项；popstate 使用原文档中保存的旧内容。/away 是另一份真实文档，可用浏览器后退。pageshow.persisted 记录实际浏览器缓存恢复，不人为伪造；浏览器不启用 BFCache 时仍有跨文档往返。publish 改供方数据，不自动更新已恢复页面。

## 通用控制

`GET /api/snapshot` 查看当前原始源状态；`POST /api/action` 接收 JSON 对象 `{"action":"动作名"}`。可用动作：reset、publish。控制只改变模拟源，不代表接收器已经处理了变化。

所有资料均由本项目构造，包含的机构、设备、会话和文件仅供本地使用，不访问真实账号。浏览器操作应通过正常可见界面；测试用源控制接口不是业务采集捷径。

## 来源证据

源端请求记录只用于核查服务行为，接收器自身的审计、状态和输出需由扩展功能负责。源端重启会恢复默认资料，但本地接收文件不会自动清空。
